# talentbridge
Sistema para conectar necesidades con oficios

## Configuración pública

- `APP_PUBLIC_URL`: URL pública canónica del sitio. Por defecto: `https://www.talentbridge.cl`.
- `GOOGLE_ANALYTICS_MEASUREMENT_ID`: identificador de medición de una propiedad GA4 (formato `G-XXXXXXXXXX`). Si se omite, Analytics y el aviso de consentimiento permanecen desactivados.

Google Analytics solo se carga cuando el visitante acepta la medición desde el aviso de privacidad. La preferencia se puede modificar desde el pie de página.
